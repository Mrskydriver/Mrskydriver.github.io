Privacy Policy – BFY Uploader

Last updated: 11 November 2026

BFY Uploader is a private tool of the YouTube channel Built for Yesterday. Only the channel owner uses it, and only for the owner's own channel.

What data the tool accesses

  • YouTube data of the owner's own channel through the YouTube Data API and YouTube Analytics API: video metadata, uploads, thumbnails, captions and channel analytics.
  • No data of other YouTube users or viewers is collected.

How the data is used

The data is used only to upload and schedule the channel's own videos and to evaluate the channel's own performance. It is not sold, shared or transferred to third parties and not used for advertising.

Storage

Access tokens and analytics reports are stored locally on the owner's computer. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

BFY Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
